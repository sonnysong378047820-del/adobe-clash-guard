不要把 AdobeClashGuard.exe 单独拷出来使用，也不要只发这一个文件；它依赖同目录的 _internal。要发给别人就发整个 ZIP。

为什么用文件夹版

2.1.0 是单文件版，运行时先把自己解压到 %TEMP%\_MEIxxxxxx，退出时删除。若安全软件正在扫描里面某个 DLL，删除失败就会弹出 Failed to remove temporary directory 警告。该警告无害，但容易误解。

2.1.1 改为文件夹版后不再向临时目录解压，该警告不会再出现，启动也更快；代价是分发物由单个 exe 变成一个文件夹（仍以 ZIP 交付）。

首次运行可能被系统拦截

程序没有代码签名证书，Windows 或安全软件对首次运行作出提示是正常现象，不是程序损坏，也不需要为此关闭安全软件。

现象处理
蓝色窗口"Windows 已保护你的电脑"点「更多信息」→「仍要运行」
安全软件提示"未知程序 / 风险程序"选择允许运行或加入信任；不要关闭实时防护
提示需要更高权限用当前同一个账户右键「以管理员身份运行」
提示"另一个安装窗口已打开"先关掉已打开的检查器弹窗，再重试
程序被隔离从隔离区还原并加入信任，再重新解压一次

公共桌面（C:\Users\Public\Desktop）上的 Clash 图标通常需要管理员权限才能修改，因此首次运行建议直接用"以管理员身份运行"。不要换成别人的管理员账户，也不要使用来源不明的"免杀/破解"版程序。

安装流程

  1. 完整解压 ZIP，双击 AdobeClashGuard\AdobeClashGuard.exe（首次建议右键以管理员身份运行）。
  2. 自动只读扫描当前用户桌面、公共桌面（顶层 .lnk），以及用户级与公共开始菜单（递归，跳过「启动」文件夹），不全盘搜索。
  3. 自动选中识别到的 Adobe 和 Clash 入口并直接接入（2.2.1 起不再弹是/否确认框）。
  4. 逐批最多 10 个，先备份校验再接入；首个失败即停止。
  5. 看到"接入成功，并已校验"才算完成，随后用原图标测试。

保留原名称、图标、参数、工作目录、窗口状态和管理员标记。安装到 %LOCALAPPDATA%\AdobeClashGuard\v2.1（目录名自 2.1 起保持不变，好让已接入图标自动沿用新程序）；恢复入口"恢复 Adobe 与 Clash 原图标.lnk"也在该目录。固定目录不要删除，原下载包不是运行依赖。

2.2.1 起：接入不再需要你点确认框，双击即可。旧的「补充接入」入口会在动手前弹一个是/否框，而它的默认焦点不在「是」上——按 Esc、点「否」或当成普通提示关掉都等于取消，结果就是"点了程序却没反应"。现在的入口带 RunAsUser 标志，双击即弹 UAC，点「是」后自动跑完；即便双击的是解压目录里没带标志的 AdobeClashGuard.exe，程序发现公共开始菜单写不了时会自己再请求一次提权，拒绝则明确报错且不改任何图标。运行时的一切都记进 install-log.txt。

改动拦截名单：blockers.txt

工具靠进程名判断对方是否在运行。内置名单为 clash-verge.exe、clash verge.exe、verge-mihomo.exe、verge-mihomo-alpha.exe、mihomo.exe、mihomo-alpha.exe、clash.exe、clash-meta.exe。

要加入别的代理软件或换内核，直接编辑固定安装目录里的 blockers.txt：一行一个进程名（带 .exe，不区分大小写），# 开头是注释。保存即生效，不用重新安装或重启。

更新与升级

  • 直接运行新版文件夹里的 AdobeClashGuard.exe 就是升级：替换固定目录里的程序，并保留 AdobeClashGuard.previous.exe 作回滚；同时自动整理 state.json（清掉中止安装留下的无效记录）并补上 blockers.txt（已存在则不覆盖）。
  • 已接入的图标无需重新接入，它们指向固定的 AdobeClashGuard.exe。
  • 升级前先关闭正在运行的检查器窗口，否则文件被占用会报错（程序会明确提示）。
  • 若没有需要新接入的图标，会提示"检查器已更新"，不修改任何快捷方式。
  • Clash / Adobe 自身更新后若换了路径、快捷方式或进程名，需先恢复原图标，取得新快捷方式再重新接入。
  • Clash Verge 每次更新都会重建自己的快捷方式，等于静默解除拦截。更新后重跑一次固定安装目录里的「补充接入 Adobe 与 Clash 图标.lnk」即可重新接入。
  • 想确认拦截是否还在生效：运行 AdobeClashGuard.exe --scan <报告文件路径>，报告里的 tampered 字段会列出被其他程序改写的受管图标；为空即全部完好。

边界：不是全系统互斥。Clash 自启动、直接 EXE、任务栏固定图标、PSD/JPG 文件关联、多用户、延迟子进程和未知进程可能绕过（开始菜单入口自 2.2.0 起已纳入扫描并受管）。自己关闭 Clash 自启动、只用受管图标，日常双向提醒才有效。本工具不改服务与开机设置、不自动杀 Adobe、不保证解决网络问题。

从旧版升级（1.x / 2.0 单文件版）

旧版是单文件打包，只有单向检查（Clash 拦 Adobe）。新版会跳过已接入旧版的图标，既不会自动升级它们，也不会覆盖旧程序目录。想把它们统一到新版：先用旧版自带的恢复入口把图标还原成原始快捷方式，再运行本安装器重新接入。每一步都要确认路径、备份与校验，不要直接删除旧程序目录。

恢复

  • 恢复原图标：Win+R 输入 %LOCALAPPDATA%\AdobeClashGuard\v2.1 回车，运行"恢复 Adobe 与 Clash 原图标.lnk"。逐批确认后先备份当前受管图标，再恢复原文件；被其他程序改动过的图标不会被覆盖，备份与程序都不会删除。
  • 程序回滚：固定安装目录内的 AdobeClashGuard.previous.exe 就是升级前的上一版程序。
  • 恢复不依赖解压目录，也不依赖当初从哪个 ZIP 安装。

没有 Clash 桌面图标怎么办

先手动创建 Clash 桌面快捷方式，再运行安装器自动识别。只有托盘/自启动入口不会获得反向拦截。Clash 安装服务、Adobe 更新/IPC 后台服务不拦截；Creative Cloud 应用本身会阻止 Clash。
